# 易学堂 · 周易与梅花易数入门

面向零基础学习者的中文学习 Web 应用（手机优先，电脑可用），数据保存在浏览器 localStorage。

- **今日一课**：主线 86 天按天解锁（每课约 10~15 分钟 + 3~5 道练习），完成即打卡；漏学的课进入“待补”。与每日 PDF 讲义同课同序：第 1–21 天阴阳、爻、八卦、六十四卦结构，第 22–86 天依通行本卦序每天一卦（第 30 天总复习），每卦先拆上下卦推出卦义再读原文。
- **选修**：「原理」13 课（先天数与方位、五行、类象、爻位、互变的来历），学完第 30 天后开放；「梅花易数」10 课，学完原理后开放。可导出讲义（Markdown / 打印）。
- **图鉴**：六十四卦卦画、上下卦、卦辞、大象、爻辞（通行本）与白话简释。
- **练习**：八卦与六十四卦闪卡/测验，Leitner 间隔重复，错题本。
- **起卦**：梅花易数时间起卦（自动换算农历）、数字起卦，给出本卦/互卦/变卦/动爻/体用/生克/卦气及完整计算步骤，可保存占例与复盘。

```bash
npm install
npm run dev      # 开发预览
npm run check    # 数据与起卦算法自检
npm run build
```

经文据维基文库《周易》整理为简体，异文按通行本（王弼注本系统）取舍。
